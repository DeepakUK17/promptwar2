# PromptWars – AI-Powered Personalized Learning & Career Intelligence Platform

A complete, unified, AI-orchestrated learning and career intelligence platform designed for the **PromptWars Hackathon**.

Please see `promptwars/` for the complete React + TypeScript application and `promptwars-ai/` for the Python FastAPI multi-agent backend.

---

## 🚀 Quick Launch

### Frontend (`promptwars`):
```bash
cd promptwars
npm install
npm run dev
```
Runs at: `http://localhost:5173`

### AI Multi-Agent Backend (`promptwars-ai`):
```bash
cd promptwars-ai
pip install -r requirements.txt
python main.py
```
Runs at: `http://localhost:9002`
